🚀 Como Usar

Opção 1: Terminal (Recomendado)
./open-scene-builder.sh
Opção 2: Scene Builder Manual

Abra Scene Builder → File → Open → src/main/resources/fxml/

Opção 3: VS Code

Clique direito no arquivo FXML → "Open with Scene Builder"

✅ Checklist - Scene Builder Ready

  • Todos os FXMLs têm BorderPane como elemento raiz
  • Todos os componentes possuem fx:id para vinculação automática
  • Imports completos para classes JavaFX
  • Controllers vinculados via fx:controller
  • CSS externa referenciada corretamente
  • GridPane/HBox/VBox com constraints definidas
  • Projeto compila sem erros

💡 Dicas Importantes

Ao Editar no Scene Builder:

  • Sempre salve com Ctrl+S ou Cmd+S
  • Recompile o projeto: ./mvnw clean compile
  • Use o Inspector (direita) para configurar propriedades
  • Arraste componentes da Library (esquerda)
  • Vincule fx:id aos campos @FXML do Controller

Para Adicionar Novos Componentes:

<Button fx:id="meuBotao" text="Clique aqui" /> // No Controller: @FXML private Button meuBotao; @FXML public void initialize() { meuBotao.setOnAction(event -> { ... }); }
